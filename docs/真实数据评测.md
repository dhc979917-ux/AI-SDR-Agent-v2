# 真实数据评测

> 目的：在**授权的标注通话**上度量管线行为。评测结果依赖标注口径与样本代表性，不代表业务准确率承诺。

本页说明标注集格式、运行方式与指标口径。仓库内 `eval/labeled_cases.example.json` 是**合成示例**，只演示标注方法和指标输出；真实评测必须替换为授权数据。

---

## 1. 数据与授权要求

- 只使用已授权用于评测的通话录音或转写；未经授权的真实录音、客户姓名、电话不得进入仓库。
- 标注文件放在仓库外或私有目录（`var/` 已被 Git 排除），提交的只有脱敏后的指标报告。
- 每条用例标注的是**通话事实**（客户说了什么、正确的企业主体是什么），不是“希望系统输出什么”。

## 2. 标注集格式

复制 `eval/labeled_cases.example.json` 为 `eval/labeled_cases.json`（或用 `--dataset` 指定其他路径），按行填写：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` / `title` | 是 | 用例编号与名称 |
| `transcript` | 是 | 带「销售：」「客户：」角色标记的转写 |
| `data_mode` | 是 | `real`（授权真实通话）或 `synthetic` |
| `expected.intent_level` | 否 | `high` / `medium` / `low`；拒联通话按策略标 `low` |
| `expected.do_not_contact` | 否 | 客户明确拒绝再联系时标 `true` |
| `expected.entity_name` | 否 | 人工确认的企业全称（以工商登记为准）；为空则该用例不参与企业指标 |
| `expected.fields.*` | 否 | 15 个业务字段中需要核对的子集；**未知事实标 `null` 表示“未知应为空”**，不是跳过 |
| `expected.call_type` | 否 | `sales` / `service` / `invalid` / `unknown` |

标注口径与设计文档第 4 节一致：职位以客户自述为准（“张总”不等于总经理）；“设计部约 15 人”不代填设计师人数；脱敏电话保留原样。

## 3. 运行

```bash
# 规则模式（无需模型密钥）
.venv/bin/python scripts/evaluate_labeled.py --dataset eval/labeled_cases.json

# 模型模式（需要 SDR_LLM_API_KEY）
.venv/bin/python scripts/evaluate_labeled.py --dataset eval/labeled_cases.json --mode llm
```

- 企业抬头指标需要配置企查查（`SDR_ENTITY_PROVIDER=auto` 且凭据可用）；未配置时企业指标为 `null`，只测意向与字段。
- 报告输出到 `eval/artifacts/labeled-{mode}.json`，包含逐条用例的期望、实际、命中情况和耗时。
- 返回码：全部核对项通过为 0，否则为 1 并打印 MISMATCH 明细。

## 4. 指标定义

| 指标 | 定义 |
|---|---|
| `intent_class_metrics` / `intent_macro_f1` | 高/中/低三档混淆矩阵与宏平均 F1 |
| `intent_abstained_count` | 期望有等级但系统给出 `null`（异常/不足证据）的用例数 |
| `dnc_recall` | 拒联漏判的补数：期望拒联且系统判为拒联的比例；`dnc_missed_ids` 列出漏判用例 |
| `entity_top1_accuracy` | 自动确认或排名第一的候选等于标注全称的比例 |
| `entity_top3_recall` / `entity_candidate_recall` | 标注主体进入前三/全部候选的比例 |
| `entity_abstained_count` | 多候选、未匹配或检索失败而交人工的用例数 |
| `field_coverage` | 期望字段核对通过率（含“未知应为空”的核对） |

## 5. 解读边界

- 通过率、F1 只描述**这份标注集**上的行为；样本量小或有偏时数字不可外推。
- 企业 Top-1 只在配置企查查后有意义；`captured`（保留原话）不算错误，也不算命中。
- 模型模式的分数会随提示词版本变化；报告保留 `dataset_sha256` 与模式，便于对比。
- 评测不修改任何业务数据，不写 CRM，不触发客户联系。
