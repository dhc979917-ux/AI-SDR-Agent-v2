# 企业数据接入契约

默认企业库是4条完全合成记录，用于演示简称、同音、同品牌多主体及独立复核，不是真实工商查询结果。企业真实性与“通话客户属于该主体”是两层证据。

## 接入方式 A：可信本地目录

设置 `SDR_ENTITY_CATALOG=/绝对路径/verified-entities.json`，文件内容是 Entity 数组。由接入方核验企业资料并维护来源与有效期。主键建议采用已核验统一社会信用代码或源系统的稳定ID。

下例仅解释字段，故意设置 `verified_registry=false`；替换真实资料并完成核验后才能用于真实线索。

```json
[
  {
    "id": "replace-with-verified-entity-id",
    "name": "替换为核验后的企业全称",
    "brand": "替换为品牌名",
    "aliases": ["经核验的简称"],
    "role": "dealer",
    "area": "浙江省杭州市",
    "industry": "全屋定制",
    "status": "存续",
    "source_url": "https://your-authorized-source.example/entity/replace-id",
    "source_title": "授权企业目录",
    "observed_at": "2026-10-20",
    "valid_until": "2026-11-19",
    "data_mode": "real",
    "verified_registry": false
  }
]
```

`verified_registry` 是适配器对可信源完成校验后的承诺，不是网页只出现名称就可以设置的标签。程序检查它、来源URL、ID、时间有效期及模式；**程序不会访问链接来重新证明每一条工商事实**。证据采集及来源可信度属于适配器职责。

## 接入方式 B：授权HTTP检索接口

```dotenv
SDR_ENTITY_API_URL=https://your-authorized-provider.example/api/search
SDR_ENTITY_API_KEY=在本地配置
```

程序发出 `GET <URL>?name=<客户口述名>&limit=10`，如配置密钥则带 `Authorization: Bearer ...`。只发送口述企业名用于检索，不发送整份通话。接口返回：

```json
{"entities": []}
```

数组中每条对象遵循上面的Entity字段。完整Schema可参考 `sdr/entities.py::Entity`；字段类型严格，未知额外字段会校验失败。请求超时5秒，不跟随重定向。401/429/5xx、无效JSON和Schema失败标记为 `lookup_failed`；正常空结果标记 `ok_empty`，不把网络失败伪装成不存在该公司。最多取10条外部候选，并与本地目录去重。

## 主体确认条件

1. `id`、`source_url` 非空，`verified_registry=true`。
2. 北京日期满足 `observed_at ≤ 今天 ≤ valid_until`。
3. 真实输入只能接受 `data_mode=real` 且 `https://` 的来源；内置合成记录不会被自动用于真实线索。
4. 多个相似候选必须人工选择，不以最高排名或仅一个通过来源校验为由自动选择。单一候选的自动关联要求客户自报完整主体全称，并有“我们公司/我们是/公司全称”等归属证据；仅品牌匹配不能确认。
5. 人工补证从当前候选选择，填写关系依据；需要外部证据时使用 `https://…` 或 `crm:记录编号`。新主体确认经独立复核。

没有正确候选时暂缓并维护可信目录/外部源，然后重新分析。当前界面不允许随手输入一个公司名就宣称已经核验。

## 检索与排序

- 当前默认通过企查查 MCP 召回；本地目录模式仍使用以下规则。
- NFKC及空白标准化，比较时剥离公司后缀与括号地区。
- 名称相似取字符相似与拼音音节相似的较高值，拼音折扣0.96；召回门槛0.58。
- 排序分 = 0.50×名称匹配 + 0.30×客户关系 + 0.15×地区匹配 + 0.05×行业匹配。
- 该分数是工程排序参数，未经真实集校准；不能写成“正确概率”或代替主体核验。
- 已发布别名只在相同地区与数据模式下补充候选。最终关系判断仍单独执行。

目前字段中的地区匹配使用包含关系，行业使用一致性匹配；在真实数据中建议改用行政区代码、标准行业分类及总部分支关系表。分公司、个体工商户、更名和注销状态需适配器做更细粒度处理，不能直接从当前合成Demo推断已覆盖。
